# Language Adapters

Language adapters describe common evidence sources and dead-code hazards. They do not override project docs, build files, tests, or runtime evidence.

Use only the adapters relevant to the project:

| File | Language |
| --- | --- |
| `python.md` | Python |
| `typescript.md` | TypeScript and JavaScript |
| `rust.md` | Rust |
| `go.md` | Go |
| `java.md` | Java and JVM projects |
| `cpp.md` | C and C++ |

Adapters are warnings and checklists, not proof. A safe removal still needs project-specific evidence, validation, and the required risk-policy path.
