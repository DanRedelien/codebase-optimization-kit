# Removal And Archive

The kit is temporary. Remove or archive it after the final summary is exported and accepted changes are merged.

## Before Removal

- Export the final summary.
- Resolve durable knowledge promotion proposals.
- Confirm accepted changes are merged.
- Confirm rollback notes are no longer needed or are archived.

## Remove

Delete the installed workspace directory:

```text
.optimization-kit/
```

Then remove the managed `.gitignore` marker block if no future kit work is planned.

## Archive

If an audit trail is needed, archive only the final summary, approved implementation packets, validation notes, and rollback records. Do not archive raw private data by default.
